# HIS 课程环境安装（前端 + 后端）

本仓库 **`his_web`** 为前端（Vue），与同级的 **`his_api`** 为后端（Spring Boot 3）。  
数据库与 JDBC 默认：**`localhost:3306`**、库 **`his`**、用户 **`root`**、密码 **`123`**（与 `his_api/src/main/resources/application.properties` 一致）。建库 SQL 见 [本地HIS数据库.md](./本地HIS数据库.md)。

---

## 一、后端（his_api）

### 1. 安装 Java（JDK）

**`his_api` 使用 Spring Boot 3，需要 JDK 17 或以上**（需同时有 `java` 与 `javac`）。项目自带的 **`mvnw` / `mvnw.cmd`**（Maven Wrapper 3.3.2）会调用本机 JDK；若未设置 `JAVA_HOME`，则需在 **PATH** 中能直接运行 `java` 和 `javac`。

#### Windows

##### A. 获取安装包

- **离线安装（课堂推荐）**：在与 `his_web`、`his_api` **同级**的 **`azb`** 文件夹中，已放置 **Eclipse Temurin 17（x64）** 的 MSI 安装包，文件名一般为：  
  **`OpenJDK17-jdk-windows-x64-hotspot.msi`**  
  将整份 `azb` 文件夹拷贝到 U 盘或机房共享后，学生双击该 MSI 即可安装（无需再联网下载）。
- **在线安装**：若本机可上网，也可打开 [Adoptium（Temurin）](https://adoptium.net/) → 选择 **Version 17**、**Operating System: Windows**、**Architecture: x64**、**Package Type: JDK** → 下载 **`.msi`** 安装包。

> 需 **64 位 Windows**；32 位系统请改用官网提供的 **x86** 包或更换 64 位系统。

##### B. 运行安装程序（MSI）

1. 双击 **`OpenJDK17-jdk-windows-x64-hotspot.msi`**（或你从官网下载的 Temurin 17 MSI）。
2. 若出现「Windows 已保护你的电脑」，点 **更多信息** → **仍要运行**（仅当你信任该安装包来源时）。
3. 安装向导中建议：
   - 保持 **「Add to PATH」**（将 JDK 加入 PATH）为**勾选**（若安装器提供该选项）。
   - **安装路径**可使用默认，例如：  
     `C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot\`  
     记下该路径，下一步配置 **`JAVA_HOME`** 时要与此**完全一致**（到 JDK 根目录，不要写到 `\bin`）。
4. 一路 **Next** → **Install**；若弹出 UAC，选 **是**。安装结束后点 **Finish**。

##### C. 配置环境变量（`JAVA_HOME` 与 `Path`）

若安装器已自动配置 PATH，仍建议检查 **`JAVA_HOME`**，便于 Maven、`mvnw` 与各工具统一识别。

**图形界面（Windows 10 / 11）：**

1. **Win + S** 搜索 **「编辑系统环境变量」** → 打开 → 点 **「环境变量(N)…」**。
2. 在 **「用户变量」** 或 **「系统变量」**（机房建议 **系统变量**，需管理员权限）中：
   - 点 **「新建」**：
     - **变量名**：`JAVA_HOME`
     - **变量值**：JDK 安装目录，例如  
       `C:\Program Files\Eclipse Adoptium\jdk-17.0.14.7-hotspot`  
       （以资源管理器中实际文件夹名为准，**不要**加 `\bin`）
   - 在变量列表中选中 **`Path`** → **「编辑」** → **「新建」**，增加一行：  
     `%JAVA_HOME%\bin`  
     若列表里已有类似 `C:\Program Files\Eclipse Adoptium\...\bin` 的条目，可保留其一，避免重复太多条。
3. 全部 **确定** 保存，**关闭已打开的命令提示符 / PowerShell / VS Code 终端**，重新打开后再测版本。

**快速校验（可选）：** 在新开的 **PowerShell** 中执行：

```powershell
echo $env:JAVA_HOME
Get-Command java | Select-Object Source
```

应能看到 `JAVA_HOME` 路径，且 `java` 指向 JDK 下的 `java.exe`。

##### D. 验证安装是否成功

**必须新开** 一个 **命令提示符** 或 **PowerShell**，执行：

```bat
java -version
javac -version
```

- 两行输出中都应出现 **17**（或更高），且无「不是内部或外部命令」报错。
- 若只认到 **JRE** 或版本低于 17，说明 PATH 里还有旧 Java，需调整 **`Path`**，把 **`%JAVA_HOME%\bin`** 移到与 Java 相关的条目**更靠前**的位置，或卸载冲突的旧 JDK。

##### E. 常见问题（Windows）

| 现象 | 处理 |
|------|------|
| `'java' 不是内部或外部命令` | 未配置 PATH 或未新开终端；检查 **`JAVA_HOME`** 与 **`Path` 中 `%JAVA_HOME%\bin`**。 |
| `java -version` 是 1.8，但已装 17 | **Path 顺序**优先了旧 JDK；把 **`%JAVA_HOME%\bin`** 提前，或删除旧 JDK 的 `bin` 路径。 |
| 安装 MSI 时提示权限不足 | 右键 MSI → **以管理员身份运行**。 |

#### macOS

```bash
# Homebrew 示例（Temurin 17）
brew install --cask temurin@17
```

若命令行找不到 `java`，按 `brew` 提示链接或把 JDK 的 `bin` 加入 PATH。验证：

```bash
java -version
javac -version
```

也可从 [Adoptium](https://adoptium.net/) 下载 **.pkg** 安装。

> **`mvnw` 说明**：若已设置 `JAVA_HOME`，在 Cygwin / MinGW 下脚本会规范化路径；未设置时则要求 **PATH 中可执行 `java` 与 `javac`**，否则会报错无法启动 Wrapper（与 `his_api/mvnw` 中逻辑一致）。

### 2. 安装 MySQL

#### Windows

##### 方式一：MySQL 官方安装包（推荐）

1. 打开 [MySQL 社区版下载页](https://dev.mysql.com/downloads/mysql/)，选择 **Windows**，下载 **MySQL Installer**（体积较大的完整安装器）。
2. 运行安装器，类型可选 **Developer Default** 或 **Server only**（仅数据库即可）。
3. 在 **Authentication** 步骤：按课堂统一要求将 **`root` 密码设为 `123`**（若安装器不允许弱密码，可先设复杂密码，安装完成后用 `ALTER USER` 改为 `123`，仅适合本机实验环境）。
4. **Windows Service**：勾选 **Start the MySQL Server at System Startup**，服务名一般为 `MySQL80` 或类似。
5. 安装结束后，打开 **命令提示符** 或 **PowerShell**（可将 `C:\Program Files\MySQL\MySQL Server 8.0\bin` 加入 PATH，便于直接使用 `mysql`）：

   ```bat
   mysql -u root -p
   ```

   输入密码 `123`，能进入 `mysql>` 即表示安装成功。

##### 方式二：集成环境（XAMPP / phpStudy 等）

若使用 XAMPP：安装后启动控制面板里的 **MySQL**，默认用户常为 `root`、密码空或自设，需在工具里改成与课程一致 **`123`**，或修改 `his_api` 里 `application.properties` 的数据库密码与本地一致。

##### 服务：查看是否在运行、启动、停止

MySQL 在 Windows 上一般以**服务**方式运行，服务名常见为 **`MySQL80`**（8.0）、**`MySQL57`**（5.7）等。**启动 / 停止服务通常要以管理员身份运行**。

查看服务名（PowerShell）：

```powershell
Get-Service *mysql*
```

查看状态（将 `MySQL80` 换成本机实际服务名）：

```bat
sc query MySQL80
```

`STATE` 为 **`RUNNING`** 表示正在运行，**`STOPPED`** 表示已停止。

启动、停止：

```bat
net start MySQL80
net stop MySQL80
```

图形界面：**Win + R** → `services.msc` → 找到 **MySQL** 相关服务 → 右键 **启动** / **停止**。

#### macOS

##### 方式一：Homebrew（推荐）

```bash
brew install mysql
brew services start mysql
```

首次设置 `root` 密码（若已能无密码登录，进入 MySQL 后执行）：

```sql
ALTER USER 'root'@'localhost' IDENTIFIED BY '123';
FLUSH PRIVILEGES;
```

验证：

```bash
mysql -u root -p123 -e "SELECT VERSION();"
```

##### 方式二：官网 DMG

从 [MySQL 社区版 - macOS](https://dev.mysql.com/downloads/mysql/) 下载 **DMG** 安装，将 **`root`** 密码设为课堂统一 **`123`**。

##### 方式三：Anaconda 自带的 MySQL

若本机已通过 Anaconda 安装 MySQL，启停与连接方式见 [本地HIS数据库.md](./本地HIS数据库.md) 第一节。

#### 数据库与后端对齐（必做）

1. 确认能登录：`mysql -h 127.0.0.1 -P 3306 -u root -p123`（或 `-u root -p` 再输入 `123`）。
2. 按 [本地HIS数据库.md](./本地HIS数据库.md) 执行初始化 SQL，得到库 **`his`** 及示例表。

### 3. Maven：使用项目自带 `mvnw`（推荐）

**无需单独安装 Maven**。`his_api` 目录下已有官方 **Maven Wrapper**：

- **macOS / Linux**：`./mvnw`
- **Windows**：`mvnw.cmd`

首次执行会从网络下载指定版本的 Maven（需能访问外网或使用学校镜像；若下载失败，再考虑本机安装 Maven 并配置镜像）。

常用示例（在 **`his_api` 根目录**执行）：

```bash
# macOS / Linux
./mvnw -v
./mvnw spring-boot:run
```

```bat
REM Windows（命令提示符，在 his_api 目录下）
mvnw.cmd -v
mvnw.cmd spring-boot:run
```

### 4. 启动 his_api

先启动 **MySQL**，并确认已建好 **`his`** 库（见上文）。任选下面一种方式即可。

#### 方式一：命令行（`mvnw`）

1. 在终端进入 **`his_api`** 目录（与 `his_web` 同级，例如 `…/HIS/his_api`）。
2. 执行：

   ```bash
   ./mvnw spring-boot:run
   ```

   或 Windows：

   ```bat
   mvnw.cmd spring-boot:run
   ```

3. 默认监听 **`server.port=5003`**、**`server.address=0.0.0.0`**（见 `application.properties`）。本机可访问：`http://localhost:5003`（具体接口路径以课程/Controller 为准）。

停止：在运行 `spring-boot:run` 的终端按 **Ctrl + C**。

#### 方式二：Visual Studio Code

1. 安装 [VS Code](https://code.visualstudio.com/)，在扩展市场安装：  
   - **Extension Pack for Java**（Microsoft）  
   - （推荐）**Spring Boot Extension Pack**（Microsoft）
2. **文件 → 打开文件夹**，选择 **`his_api` 根目录**（内含 `pom.xml`、`mvnw`）。
3. **配置 JDK 17+**：先点击编辑区使焦点在 VS Code 窗口内；打开命令面板可用 **Mac：`Cmd + Shift + P` 或 `F1`**，**Windows：`Ctrl + Shift + P` 或 `F1`**，或菜单 **查看 → 命令面板**。输入 **`Java: Configure Java Runtime`**，将 JDK 设为 **17+**。若无反应，在 **键盘快捷方式** 中搜索「命令面板」检查是否被改键；**Cursor** 用法相同。若未自动识别 JDK，在设置中配置 **`java.jdt.ls.java.home`**。
4. 等待右下角 **Maven 项目导入**完成（首次需联网下载依赖）。
5. 打开 **`src/main/java/com/his/SpringbootHisApplication.java`**，在 `main` 方法上方点击 **Run** 或 **Debug**；或使用侧边栏 **Spring Boot** 面板启动应用。
6. 终端/调试控制台出现 **Started …Application** 且无数据库报错即成功，端口仍为 **5003**。

停止：调试工具栏的停止按钮，或结束调试会话。

---

### 5. 后端常见问题

| 现象 | 处理思路 |
|------|----------|
| `mvnw` 提示找不到 `java` / `javac` | 安装 JDK 17+，配置 **`JAVA_HOME`** 与 **`Path`**（Windows 需新开终端）。 |
| 无法连接数据库 | 确认 MySQL 已启动；库名 **`his`**、账号密码与 `application.properties` 一致。 |
| 提示无法连接 MySQL | Windows 查 MySQL 服务是否 **RUNNING**；macOS 查 `brew services` 或 `mysql.server`。 |
| 忘记 root 密码 | 查阅本机系统的「重置 MySQL root 密码」说明。 |
| 端口被占用 | `5003` 被占用时，可改 `application.properties` 中 `server.port` 并同步告知前端配置。 |

> **安全说明**：`root` / `123` 仅用于本机教学与实验，**切勿**用于公网或生产环境。

## 二、前端（his_web）

### 1. 安装 Node.js

前端为 **Vue 2 + Vue CLI 4**，需本机安装 **Node.js**（建议 **LTS 大版本**，如 **22.x**；一般 **14+** 也可，若 `npm install` 报错可再换 LTS 版本）。

#### Windows

##### A. 获取安装包

- **离线安装（课堂推荐）**：在与 `his_web`、`his_api` **同级**的 **`azb`** 文件夹中，提供 **Windows 64 位 MSI**：  
  **`node-v22.22.2-x64.msi`**（**Node.js 22 LTS**，与 [nodejs.org/dist](https://nodejs.org/dist/) 上 **v22.22.2** 一致，适合 Vue CLI 4）。  
  将 `azb` 拷贝到 U 盘或共享目录后，学生双击安装即可。
- **在线安装**：打开 [https://nodejs.org/](https://nodejs.org/) → 下载 **LTS** 的 **Windows Installer (.msi)**，选 **64-bit**。

> 需 **64 位 Windows**。若只用 32 位系统，需到官网历史版本页下载对应的 **x86** 包（本课程 `azb` 未提供）。

##### B. 安装 MSI

1. 双击 **`node-v22.22.2-x64.msi`**（或官网下载的 `.msi`）。
2. 向导中保持默认即可；务必勾选 **「Automatically install the necessary tools」** 若你希望自动装构建工具（可选）；核心是把 **Node.js** 和 **npm** 装进系统。
3. 安装路径默认多为 `C:\Program Files\nodejs\`，一般**无需**再手工配置 `PATH`（安装器会写入）。
4. 结束安装后**关闭已打开**的命令行 / VS Code，**重新打开**再验证。

##### C. 验证

在新开的 **命令提示符** 或 **PowerShell** 中：

```bat
node -v
npm -v
```

应显示 **v22.x.x**（或你安装的 LTS 版本号），且不应报「不是内部或外部命令」。

#### macOS

- 官网下载 **LTS** 的 **macOS Installer (.pkg)**，或使用 Homebrew：`brew install node`（版本以 `brew` 为准）。  
- 安装完成后**新开**终端验证：

```bash
node -v
npm -v
```

### 2. 安装依赖

进入 **`his_web`** 目录（本课件所在仓库根目录），执行：

```bash
npm install
```

### 3. 启动开发服务器

```bash
npm run serve
```

终端会提示本地访问地址（一般为 `http://localhost:8080`，以实际输出为准）。需先保证 **后端 `his_api` 已启动**（若页面要调 `localhost:5003` 等接口）。

构建生产包：

```bash
npm run build
```

### 4. 前端常见问题

| 现象 | 处理思路 |
|------|----------|
| `npm install` 很慢或失败 | 可配置国内 npm 镜像（如淘宝 / 腾讯云镜像）后再试。 |
| 接口连不上 | 确认 **`his_api` 已启动**、端口与前端代理/请求地址一致。 |
